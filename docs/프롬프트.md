# Claude Code 프롬프트 — 디자인 적용 (v5)

디자인 캔버스 '우니스 앱 디자인 시안'의 **최종 조합 → v5**(홈 · 캘린더)를 코드로 옮기는 프롬프트입니다. 2026-11-03 정리.

## 진행 순서 (프롬프트마다 반복)

1. `git switch main` → `git pull` → 프롬프트에 적힌 브랜치 만들기 (`git switch -c feature/...`)
2. Claude Code 권한 모드를 **계획**으로 두고 프롬프트를 통째로 붙여 넣기. 캔버스 v5 화면 캡처를 같이 붙이면 더 비슷하게 나옵니다
3. 계획을 읽고 괜찮으면 **수동**으로 바꿔 진행
4. 폰에서 확인 → 커밋 → push → PR → 팀원이 Merge
5. 다음 프롬프트로

| 순서 | 프롬프트 | 브랜치 |
|---|---|---|
| 1 | 디자인 규칙 + 공통 부품 | `feature/design-system` |

| 4 (B) | 메일·시험 대비 화면 + 백업 카드 새 디자인 | `feature/mail-exam-design` |

1·2는 끝났어요 (#21 디자인 기초, #26 홈. 홈과 함께 시간표 캡쳐 #25, 모든 화면의 새 탭바도 들어감). 3은 A, 4는 B가 합니다.

## 프롬프트 1 · 디자인 규칙 + 공통 부품

```

[색]

- 일정 종류: 과제 #2756A6/#E4EBF8, 퀴즈 #22553A/#E3F1E7(점 #2F7A4C), 시험 = 포인트색/#F8EEF1, 확인 필요 #7A4300/#FFF6E8(테두리 #F2C98A, 점 #C77A00)

- 버튼 모서리 10~14px, 누를 수 있는 것은 최소 44px, 아이콘 lucide-react(선 1.8)
[레이아웃]

- 하단 탭바(흰색, 위쪽 얇은 테두리) 5칸: 홈 · 일정 · (가운데 48px 둥근 포인트색 + 버튼: 계획서·캡쳐 올리기) · 시험 대비 · 메일

끝나면 폰에서 /design을 열어 확인하는 방법을 알려 줘.
```

## 프롬프트 3 · 강의계획서 → 캘린더 확인 화면

```

[화면, 회색 바탕 위 흰 블록. 위에서 아래로]
1. 머리(블록 아님): 뒤로 버튼, 제목 "찾은 일정 N개", 아래 작은 글씨 파일 이름, 오른쪽 SegmentedTabs(목록 | 달력)
2. 달력 블록(모서리 20px):
   - 위쪽 "2026년 11월" + 이전·다음 달 버튼, 요일 줄(일~토), 날짜(Mono)
   - 오늘은 포인트색 테두리 원, 일정 있는 날은 숫자 아래 종류별 색 점, 확인 필요는 주황 점
   - 블록 아래쪽에 구분선 + 색 설명(퀴즈·과제·시험·확인 필요)
   - 날짜를 누르면 아래 체크리스트가 그날로 스크롤
3. 체크리스트 블록 "캘린더에 넣을 일정" + 오른쪽 '모두' 체크:
   - 확인 필요 일정은 맨 위 고정: 옅은 주황 띠(#FFF6E8, 위아래 #F2C98A 선), 체크박스, 제목, 원문 문구, 포인트색 '날짜 고르기' 버튼
   - 이번 달 일정은 CheckRow(체크박스, 날짜 Mono, 제목, 종류 Badge)
   - 다른 달은 접힌 줄 "9·10월 · 퀴즈·보고서·중간고사 3/3"(오른쪽 ∨), 누르면 펼침
4. '날짜 고르기' → BottomSheet:
   - 확인 필요 배지, 제목, "계획서 원문: ○○"
   - 날짜 후보 3개를 큰 버튼으로(그 주 수업 요일 우선, 아래 작은 글씨로 요일) — 고른 것은 포인트색
   - '하루 전 알림 받기' 체크, 버튼 '빼기'(회색) / '○○로 저장'(포인트색)
```

## 프롬프트 4 · 메일·시험 대비 화면 + 백업 카드 새 디자인 (B)

```

[지킬 것]

  부품 파일 자체는 A 담당이라 고치지 마. 부품에 없는 모양이 필요하면 화면 파일 안에서 만들고, 계획에 적어 줘

  옛 이름(accent, accent-soft, foreground, background)과 rounded-2xl·테두리 카드는 없애

  머리(블록 아님): 작은 회색 라벨 + 화면 제목 22px 굵게 + 한 줄 설명
  그 아래 흰 블록들(모서리 20px, 테두리·그림자 없음, 블록 사이 8~10px). 블록 안은 가는 구분선(divider)으로만 나눔
- 포인트색으로 꽉 채운 것은 화면당 하나(주요 버튼). 강조 블록(옅은 포인트 bg-brand-soft)도 블록 안에 하나만
- 입력칸: 흰 바탕 + 얇은 테두리(border-line), 모서리 12px, 높이 44px 이상. 누를 수 있는 것은 모두 44px 이상
- 숫자·점수·쪽 번호·D-day는 font-mono
- 오류 안내는 '확인 필요' 색(bg-review-soft, text-review, border-review-line)
- 아이콘은 lucide-react(선 1.8). 하단 탭바는 layout.tsx가 이미 그리니 화면에 따로 넣지 마

[화면별]
- 메일: 상황 고르기는 SegmentedTabs나 칩 버튼, 과목·하고 싶은 말 입력, '초안 만들기'(주요 버튼),
  스트리밍되는 초안은 흰 블록 안에, 복사 버튼은 secondary
- 시험 대비: 자료 올리기·쪽 범위 → 요약 5줄·어려운 말(블록) → 10문제(문제마다 구분선), 채점 결과 점수는 Mono 큰 숫자,
  틀린 문제 다시 풀기. 정답·오답 표시는 퀴즈 색(quiz)·포인트색으로
- 백업 카드: 설정 창(BottomSheet) 안에 들어가므로 바깥 테두리 카드 없이, 제목 15px 굵게 + 설명 + 버튼 두 개(secondary)

끝나면 확인: 폰(375px)에서 두 화면을 처음부터 끝까지 한 번씩 써 보고(메일 초안 1개, 퀴즈 1번 채점),
가로로 넘치는 곳이 없는지, 홈 설정 창의 백업 카드 모양. next build·ESLint 통과.
```
