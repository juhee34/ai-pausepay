# 우니스 디자인 규칙

모든 화면은 이 문서를 따릅니다. 색·글꼴·모서리는 `web/src/app/globals.css`의 `@theme`에 이름으로 등록되어 있으니, 코드에서는 색 코드(#…) 대신 **이름**(`bg-brand`, `text-muted` 등)을 씁니다.
모양만 있는 공통 부품은 `web/src/components/ui`에 있고, 폰에서 `/design`을 열면 모두 모아 볼 수 있습니다.

## 모양

- **블록형**: 회색 바탕(`canvas`) 위에 흰 블록(`surface`).
  - 블록은 테두리·그림자 없이 모서리 18~20px (`rounded-block` 20px, `rounded-block-sm` 18px).
  - 블록 사이는 8~10px (`gap-2`~`gap-2.5`).
- 블록 안은 **가는 구분선(`divider`)으로만** 나눕니다.
- 블록 안 강조 블록(옅은 포인트, 모서리 16px `rounded-callout`)은 **하나만** 둡니다(AI 추천).
- 좌우 여백 16px (`px-4`), 블록 안쪽 여백 12~14px (`p-3`~`p-3.5`).
- **같은 정보·바로가기를 두 곳에 두지 않습니다.** 기능 사이 이동은 하단 탭바에서 합니다.
- 버튼 모서리 10~14px (`rounded-button` 12px).
- 누를 수 있는 것은 **최소 44px** (`min-h-11`).
- 아이콘은 `lucide-react`, 선 굵기 1.8 (`strokeWidth={1.8}`).

## 레이아웃

- 폰(폭 375~430px) 기준으로 만듭니다. PC에서는 가운데에 **최대 폭 480px**.
- **하단 탭바** (흰색, 위쪽 얇은 테두리 `line`), 5칸:
  - 홈 `/` · 메일 `/mail` · **＋** · 시험 대비 `/exam` · 마이페이지 `/my`
  - 가운데 ＋는 48px 둥근 포인트색 버튼. 누르면 **전체 기능** 창(`BottomSheet`)이 올라와 여러 기능을 한눈에 고릅니다. 새 기능은 탭을 늘리지 않고 이 창에 더합니다.
  - 전체 기능 창: 묶음마다 작은 회색 라벨(11px) + **2열 타일**(흰 블록 안, 모서리 14px, 높이 64px 이상, 왼쪽 아이콘 22px + 기능 이름 14px 굵게 + 한 줄 설명 11px `muted`).

    | 묶음 | 타일 (주소) |
    |---|---|
    | 학점 | 오늘의 한 가지 `/today` · 기말 필요 점수 `/grades` · 학기 리스크 지도 `/risk` · 집중 모드 `/focus` |
    | 취업 준비 | 공고·자격증 올리기 `/calendar?type=posting` · 대외활동 `/career` · 스펙 영수증 `/career/receipts` · 역량 공백 지도 `/career/skills` |
    | 내 정보 | 시간표 캡쳐 `/timetable` |

    아직 없는 화면의 타일은 흐리게 + '준비 중' 배지(누르면 "곧 열려요"). 탭바에 있는 기능(메일·시험 대비·마이페이지)은 이 창에 다시 넣지 않습니다.
  - 일정은 홈에 있습니다(큰 달력, 고른 날의 일정, 저장된 일정 목록). 계획서·캡쳐 올리기는 홈 오른쪽 위 메뉴(막대 3개, `BottomSheet`) 안의 '강의계획서 넣기'로 `/calendar`에서 합니다. 시간표 바꾸기와 내보내기·가져오기도 이 메뉴에 있습니다.

## 분석 화면 (시안 '학점을 위한 의사결정' · '역량 공백 지도')

숫자를 계산해 보여 주는 화면(오늘의 한 가지, 최소 점수 계산, 학기 리스크 지도, 역량 공백 지도, 나중의 학기 결산서)은 시안을 **그대로** 따릅니다. 캡처: `docs/design-ref/` (원본: claude.ai 디자인 '이것저것...?'). 위 규칙에 더해 아래를 지킵니다.

### 화면 틀
- 맨 위 왼쪽: 다른 분석 화면에서 왔으면 포인트색 작은 글씨 뒤로 링크(`< 오늘의 한 가지`), 아니면 포인트색 '우니스' 글자. 오른쪽: 예시 데이터일 때만 흰 알약 `예시 데이터`(11px, 테두리 `line`)
- 화면 제목(22px 굵게) 아래에 보조 글 한 줄(12~13px `muted`) — 기준이나 한 줄 설명
- 포인트색으로 꽉 채운 **큰 숫자 블록은 화면당 하나**: 작은 라벨(12px, 흰색 80%) → 문장 또는 큰 숫자(`font-mono` 40px 굵게, 단위는 15px) → 보조 글 → 필요하면 흰 알약 배지
- 분석 화면끼리는 맨 아래 **테두리 버튼**(흰 바탕, 포인트색 1px 테두리·글자, 모서리 12px, 오른쪽 `>`)으로 이어 갑니다: 오늘의 한 가지 → 최소 점수 계산 → 학기 리스크 지도 → 오늘의 한 가지. 탭바 규칙의 예외로, 같은 묶음 안에서만 씁니다
- 맨 아래 **계산식 각주**: 11px `muted`, "효율 = 배점 × … 화면의 숫자는 모두 예시 데이터예요."처럼 계산 방법을 한두 문장으로

### 고르기
- 과목·목표 직무·시간 같은 고르기는 **칩 버튼**: 높이 40px, 모서리 끝까지 둥글게(`rounded-full`), 고른 것은 포인트색 채움 + 흰 글자, 나머지는 흰 바탕 + 회색 테두리
- 목표 점수처럼 숫자를 정할 때는 슬라이더(포인트색) + 아래에 기준 칩(`A+ 95`, `A0 90`…, `font-mono`)

### 칸·막대
- **역량 칸**(공백 지도): 2열 칸, 모서리 14px. 채움 = 포인트색 1px 테두리, 보강 필요 = `review-line` 1px 테두리, 비어 있음 = 회색 **점선** 테두리. 오른쪽 위 점 3개(채운 수만큼 포인트색)
- **진행 막대**: 높이 6px, 모서리 끝까지 둥글게, 바탕 `divider`. 1등·추천은 포인트색, 나머지는 옅은 보라회색(`#A89BB0`)
- **위치 막대**(최소 점수): 여유(초록 옅게) · 주의(주황 옅게) · 위험(분홍 옅게) 세 칸, 내 값 위치에 검은 세로선 + 위에 검은 숫자 말풍선(`font-mono`)
- **부담 표**(리스크 지도): 칸 32px 정사각형, 모서리 6px, 숫자 `font-mono` 12px. 값에 따라 4단계(`#F8EEF1` → `#E8BFCB` → `#C25C7A` → `#8C1D40`, 진한 두 단계는 흰 글자), 0은 회색 `·`. 몰린 주는 검정 칸 + 아래 포인트색 '몰림'. 이번 주 열 머리는 포인트색
- **경고 블록**: 옅은 포인트 바탕(`brand-soft`) 블록, 제목 15px 굵게 포인트색 + 설명 13px
