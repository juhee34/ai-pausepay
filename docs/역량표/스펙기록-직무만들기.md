# 스펙 기록 구분 · 자소서 역량 30개 · 직무 만들기

2026-11-12 · A(juhee34) 정리 · 같은 폴더 `competencies.ts`가 새 역량 목록입니다 (11/5 판을 대체).

## 왜 바꾸나

- 역량 공백 지도는 직무 4개(마케팅 기획·데이터 분석·서비스 기획·재무·회계)만 고를 수 있어서, 다른 직무를 준비하는 학생은 쓸 수 없어요.
- 스펙 영수증은 STAR로 길게 쓰는 방식만 있어서, 자격증·어학처럼 짧게 남기면 되는 스펙은 넣기 번거로워요.

## 1. 자소서 역량 30개

NCS 직업기초능력 하위능력과 직업공통능력(2026.4.28 개편)을 학생이 쓰는 말로 바꿨어요. 뜻·근거는 `competencies.ts`의 `COMPETENCY_INFO`에 있어요.

| 묶음 | 역량 6개 |
|---|---|
| 일하는 태도 | 책임감 · 성실성 · 도전정신 · 주도성 · 끈기 · 꼼꼼함 |
| 함께 일하기 | 협업 · 리더십 · 소통 · 설득·발표 · 갈등 조정 · 고객 지향 |
| 생각하는 힘 | 문제 해결 · 분석력 · 창의성 · 기획력 · 의사결정 · 전략적 사고 |
| 실행과 관리 | 실행력 · 일정 관리 · 자원·예산 관리 · 위기 대처 · 변화 적응 · 학습 능력 |
| 도구와 전문성 | 문서 작성 · 외국어 활용 · 데이터 활용 · 디지털·AI 활용 · 전공 지식 활용 · 직업윤리 |

추천 직무 4개의 전문 역량 19개(11/5 표)는 그대로 둬요. 추천 직무의 8칸 = 전문 역량 5개 + 그 직무에 맞는 자소서 역량 3개예요.

| 추천 직무 | 자소서 역량 3개 |
|---|---|
| 마케팅 기획 | 창의성 · 협업 · 소통 |
| 데이터 분석 | 문제 해결 · 꼼꼼함 · 소통 |
| 서비스 기획 | 문제 해결 · 협업 · 소통 |
| 재무·회계 | 꼼꼼함 · 책임감 · 직업윤리 |

## 2. 기록 구분 9개 → 간단 기록

영수증 쓰기 첫 화면에서 구분을 고르면, 그 구분에 맞는 칸 1~3개와 추천 역량 3개가 나와요.

| 구분 | 칸 | 처음 보여 줄 역량 |
|---|---|---|
| 대외활동·동아리 | 맡은 역할 · 기간 | 협업 · 리더십 · 주도성 |
| 인턴·아르바이트 | 회사·가게 · 맡은 일 · 기간 | 책임감 · 고객 지향 · 성실성 |
| 프로젝트·공모전 | 맡은 역할 · 결과 | 문제 해결 · 기획력 · 협업 |
| 수업·과제 | 과목 · 학기 | 분석력 · 문서 작성 · 협업 |
| 교육·부트캠프 | 기관 · 기간·시간 | 학습 능력 · 디지털·AI 활용 · 전공 지식 활용 |
| 자격증 | 취득일 · 발급 기관 | 학습 능력 · 끈기 · 전공 지식 활용 |
| 어학 | 점수·등급 · 응시일 | 외국어 활용 · 학습 능력 · 끈기 |
| 수상 | 상 이름 · 날짜 | 도전정신 · 창의성 · 실행력 |
| 봉사·기타 | 기간 | 책임감 · 직업윤리 · 소통 |

흐름: 구분 고르기 → 이름 + 칸 + 한 줄 메모 → **어필할 역량 버튼 최대 3개** (추천 3개 먼저, '더 보기'에 30개 묶음별 + 목표 직무의 전문 역량) → `기록 저장`.
길게 쓰고 싶으면 `STAR로 자세히 정리하기`를 눌러 지금의 AI 영수증 흐름으로 이어져요. 간단 기록도 공백 지도에서 한 장으로 셉니다.

## 3. 직무 만들기

역량 공백 지도의 직무 칩 끝에 `＋ 직무 만들기`를 둬요.

- 직무 이름(20자까지)을 적고, 역량 버튼에서 **6~10개**를 골라요. 버튼은 자소서 역량 30개(묶음별)와 추천 직무의 전문 역량이에요.
- 만든 직무는 추천 직무 옆에 칩으로 나오고, 편집·삭제할 수 있어요.
- AI는 쓰지 않아요.

## 데이터 (기존 기록이 그대로 읽혀야 함)

- 영수증 저장 키 `unis.receipts.v1`는 그대로. 영수증에 선택 칸 `kind`(구분)와 `detail`(칸 값)을 더해요. 옛 영수증엔 없어도 돼요.
- 간단 기록은 같은 영수증으로 저장하고, STAR 칸은 빈 글자, 한 줄 메모는 `oneLiner`에 넣어요. 그래서 파일·계정 백업 검사(`isReceipt`)를 바꾸지 않아도 통과해요.
- 옛 역량 이름은 읽을 때 바꿔요(`normalizeCompetencies`). `협업·리더십`은 `협업`과 `리더십` 둘로 나뉘어요.
- 만든 직무는 새 키 `unis.customJobs.v1`에 보관하고, 파일·계정 백업에 넣어요.
- 목표 직무 값은 추천 직무 이름 또는 `custom:<id>`. **지금 백업 가져오기는 표에 없는 목표 직무가 있으면 파일 전체를 거절**하므로, 이를 "목표 직무만 빼고 나머지는 가져오기"로 바꿔야 해요.

## 2차 수정 (11/12) · `코드초안/career-nav-posting.patch`

1차 패치 위에 적용하는 변경이에요 (파일 14개).

- **내 직무만 쓰기:** 직무를 하나라도 만들면 예시 직무 4개(마케팅 기획 등) 칩과 마케팅 기획 예시 데이터가 사라지고, 내가 만든 직무로만 계산해요. 만든 직무를 모두 지우면 예시 직무가 다시 나와요. 영수증 역량 고르기의 '더 보기'에도 예시 직무 대신 내 직무 역량 묶음이 맨 위에 나와요.
- **뒤로가기:** 시간표 캡쳐 → 홈. 공고·자격증 올리기·스펙 영수증·역량 공백 지도 → 취업. (영수증 쓰기 화면은 스펙 영수증으로 돌아가요.)
- **공고·자격증 올리기를 취업 안으로:** 새 주소 `/career/posting`. 옛 주소 `/calendar?type=posting`은 새 주소로 보내고, 강의계획서 화면의 '강의계획서/공고·자격증' 탭은 뺐어요. 전체 기능 창·홈 링크도 새 주소로.
- **활동 추가와 안 겹치게:** 취업 화면 맨 위에 '공고·자격증 올리기'(AI가 마감을 찾아 일정과 활동을 함께 만듦)를 크게 두고, 대외활동 목록의 버튼은 '직접 추가'(공고 없이 손으로 적기)로 이름을 바꿨어요. 직접 추가 창 맨 위에 공고가 있으면 공고·자격증 올리기로 가라는 안내를 넣었어요. 화면 제목은 '대외활동' → '취업 준비'.

확인: `next build`·ESLint·단위 테스트 26개 통과, 폰 375px에서 뒤로가기 주소 4곳, 옛 공고 주소 이동, 직무 만들기 후 예시 직무·예시 데이터가 사라지는지 확인했어요.
