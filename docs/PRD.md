# 우니스 PRD (기능 명세)

2026-11-03 기준. 기능 범위나 일정이 바뀌면 이 문서를 먼저 고칩니다.

## 한 줄 소개
대학생을 위한 AI 학업 비서. 강의계획서 한 장을 올리면 한 학기 일정이 생기고, 그 일정이 오늘 할 일 → 시험 대비로 이어집니다.

**이름의 뜻**: UNIS = **UNIfied Student**. UNI는 '하나'(unify), S는 학생(Student). "흩어진 대학 생활을 하나로 잇는 학생 비서"라는 뜻입니다.

## 풀려는 문제
- **앱이 흩어져 있다**: 시간표·과제·요약·메일이 제각각 다른 앱에 있다.
- **우리 학교를 모른다**: 해외 앱은 학교별 일정·규칙을 모른다.
- **한 일이 남지 않는다**: 학기 중 한 일이 기록으로 남지 않는다.

## 누구를 위한가 (가상 페르소나)
- **지원** — 경영학부 3학년, 복수전공 필수. "두 전공 요건표를 번갈아 보다 하루가 가요"
- **민재** — 2학년, 대외활동 3개 병행. "오늘 뭐가 제일 급한지 모르겠어요"

## 발표 데모 흐름 (1분)
강의계획서 올리기 → 캘린더 → 오늘의 브리핑 → 시험 대비 팩. 이 한 흐름을 가장 매끄럽게 만듭니다.

## 핵심 1. 강의계획서 → 캘린더 (대표 기능)
- **누가·언제**: 개강 첫 주, 수강 과목의 강의계획서를 받았을 때
- **무엇을**: 강의계획서 PDF나 **KLAS 화면 캡쳐(이미지)**를 올리면 AI가 과제·퀴즈·중간·기말 날짜를 뽑아, 확인 후 캘린더 파일(.ics)로 내려받는다.
- **흐름**
  1. PDF 또는 캡쳐 이미지(PNG·JPG) 선택 → 올리기 전 크기 확인 (4MB 넘으면 안내)
  2. `web/src/app/api/syllabus`에서 Claude API가 `{과목, 제목, 날짜, 종류(과제/퀴즈/중간/기말/기타)}` 목록(JSON)을 돌려줌 → `zod`로 형식 검사
  3. 날짜 확인·수정 화면 (사용자가 고친 뒤에 저장)
  4. `localStorage`에 저장 + `.ics` 내려받기 (알림 포함) → 구글·애플 캘린더에 추가
- **하지 않을 것**: KLAS 로그인·자동 가져오기, 올린 PDF·이미지 서버 저장
- **끝났다는 기준**
  - 모은 강의계획서 PDF 6개 중 5개 이상에서 날짜가 맞다
  - 구글 캘린더와 아이폰 캘린더에 일정이 들어가고, 두 사람 폰에서 알림이 울린다
  - 5MB PDF를 고르면 안내가 뜨고 오류 화면이 나오지 않는다
- **만드는 순서**: AI 없이 가짜 날짜 3개 목록 화면 → AI 연결 → 확인·수정 + .ics
- **참고**: [Syllabus-to-Calendar-App](https://github.com/MahalakshmiPFW/Syllabus-to-Calendar-App) (MIT), `ics` 패키지

## 핵심 2. 오늘의 브리핑 (홈 화면)
- **누가·언제**: 매일 앱을 열었을 때
- **무엇을**: 오늘 할 일을 한 화면에 모아 보여 주고, 지금 시작할 일 하나를 추천한다.
- **화면**
  - 맨 위: AI가 추천하는 '지금 시작할 일' 한 줄
  - 다음 수업·오늘 수업 시간: KLAS 시간표 캡쳐를 올리면 AI가 표로 읽고, 사용자가 확인·수정한 뒤 이 폰에만 저장 (`/timetable`, 2026-11-03 추가)
  - 카드: 캘린더에 저장한 일정 중 오늘·이번 주 마감 (D-day)
  - 카드: 대외활동 일정 (직접 추가)
  - 데이터 내보내기·가져오기 버튼, '홈 화면에 추가' 안내 카드 (아이폰은 7일 동안 안 열면 저장 데이터가 지워질 수 있음)
  - (제안) '어제 공부 시간' 카드는 집중 모드를 만들면 그때 추가하고, 없으면 숨긴다
- **알림**: 웹 푸시 알림은 만들지 않는다. 알림은 .ics 일정으로 폰 캘린더가 맡고, 브리핑은 "앱을 열면 바로 보이는 것"
- **끝났다는 기준**
  - 홈에서 오늘 마감이 보인다
  - 내보낸 파일로 다른 폰에서 기록이 복원된다

## 핵심 3. 시험 대비 팩
- **누가·언제**: 시험 2~3주 전, 강의자료로 복습할 때
- **무엇을**: 강의자료(PDF나 텍스트)를 넣으면 ① 5줄 요약과 어려운 말 풀이 ② 객관식·OX 10문제 ③ 채점 ④ 틀린 문제만 다시 풀기
- **조건**: 쪽 범위 선택 (큰 자료는 나눠서 보내기), 올린 자료는 서버에 저장하지 않음, 퀴즈에는 해설 포함
- **끝났다는 기준**
  - 테스트 자료 3개(본인 필기·공개 자료) 모두 퀴즈 10문제가 나온다
  - 4MB가 넘는 자료도 범위를 골라 퀴즈가 나온다
- **참고**: [PDF to Quiz Generator](https://vercel.com/templates/next.js/pdf-to-quiz-generator), `unpdf`

## 핵심 4. 교수님 메일 작성기
- **누가·언제**: 교수님께 메일을 보내야 할 때
- **무엇을**: 상황을 고르고 과목명·학번·하고 싶은 말을 넣으면 예절에 맞는 초안과 보내기 전 체크리스트가 나온다.
- **상황 5개**: 성적 문의, 결석 사유, 추천서 부탁, 면담 요청, 과제 연장
- **체크리스트**: 제목에 과목명·학번, 첨부파일, 보내는 시간
- **화면**: 복사 버튼 ("복사했어요" 알림)
- **끝났다는 기준**: 5개 상황 모두 초안이 나온다
- 첫 AI 기능으로 연습하기 좋음: 여기서 하루 사용 횟수 제한·길이 상한·스트리밍을 먼저 만들어 다른 기능에 재사용

## 제외
- **KLAS 직접 연동**: 공식 API가 없고 비공식 연동은 보안·약관 문제. 대신 사용자가 KLAS 화면을 캡쳐해 올리면 AI가 인식한다 (핵심 1)
- **사용 기록 수집(Supabase)**: 이번 학기에는 만들 시간이 없어 뺌. 경영학 분석은 설문·인터뷰·비용으로 대신함

## 모든 기능 공통
- **개인정보**: 개인 데이터는 폰(브라우저)에만. 서버에는 아무것도 저장하지 않음
- **저작권**: 올린 강의자료는 저장·공유하지 않음, 화면에 안내 문구
- **AI 오류**: 날짜는 사용자 확인 후 저장, 퀴즈는 해설과 함께, 리서치는 출처 링크
- **비용·남용**: 콘솔 월 사용 한도, 기기당 하루 횟수 제한, 입력·답변 길이 상한, 빠른 모델 기본
- **속도**: 답변 스트리밍과 진행 상태 표시
- **PDF·이미지 크기**: 4MB 넘으면 안내 (Vercel 4.5MB, Claude PDF 32MB·100쪽, 이미지 1장 5MB)

## 아직 정하지 않은 것
- KLAS 캡쳐 인식의 '끝났다는 기준' (어떤 화면을 몇 장 테스트할지)
- 하루 AI 사용 횟수 (예시는 20회)
- 소개서 문구 "묻기 전에 먼저 챙깁니다"를 실제 동작에 맞게 고칠지
