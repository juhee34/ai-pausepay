# 우니스(UNIS) 서비스 소개서

> 원본: claude.ai 문서 '우니스(UNIS) 서비스 소개서' (2026-09-29 작성, 외부 공유용).
> **2026-11-03 수정**: 대상 문구를 '대학생'으로 바꾸고, 기능을 핵심 4개 + 추가 예정으로 나눴으며, 인사이트를 설문 기반 분석으로 바꿨습니다. 이름의 뜻은 **UNIfied Student**로 정했습니다(2026-11-02). 기능 범위는 `docs/PRD.md`가 우선입니다.

**대학생을 위한 AI 학업 비서** — 강의계획서 한 장으로 시작해, 한 학기를 먼저 챙겨 주는 자비스.
키워드: 강의계획서 → 일정 · 오늘 할 일 · 시험 대비 AI

**UNIS = UNIfied Student** — UNI는 '하나'(unify), S는 학생(Student). 흩어진 대학 생활을 하나로 잇는 학생 비서.

**대학생을 위한 자비스, 우니스(UNIS).** 아이언맨의 자비스처럼, 묻기 전에 먼저 챙깁니다. 강의계획서를 올리면 한 학기 일정이 생기고, 그 일정이 오늘 할 일 → 시험 대비로 이어집니다. 첫 사용자는 광운대생입니다.

## 문제

AI는 매일 쓰지만, 학교생활은 여전히 흩어져 있다.

| 문제 | 설명 |
|---|---|
| **앱이 흩어져 있다** | 시간표·과제·요약·메일이 제각각 다른 앱에 있다 |
| **우리 학교를 모른다** | 해외 앱은 우리 학교 일정·졸업요건·복수전공을 모른다 |
| **한 일이 남지 않는다** | 대외활동은 했는데 자소서 쓸 땐 기억이 안 난다 |

대학생 10명 중 9명이 생성형 AI를 씁니다(92%, [영국 HEPI 2025, ZDNet](https://zdnet.co.kr/view/?no=20250227084114)). 국내 대학생의 주된 용도는 **과제·리포트** 28.6%, **번역·요약** 27.6%입니다([스타트업레시피, 69명 설문](https://startuprecipe.co.kr/archives/invest-report/5803994)). 도구는 늘었지만, 내 일정·내 학교·내 기록을 이어 주는 곳은 없습니다.

## 누구를 위한 서비스인가

두 대학생, 두 가지 하루 (가상 페르소나, 첫 시범 대상은 광운대생)

### 지원 — 경영학부 3학년 · 복수전공 필수
> "두 전공 요건표를 번갈아 보다 하루가 가요"

- 고민: 두 전공 졸업요건이 헷갈린다 · 겹쳐 인정되는 과목을 모른다 · 전공 과제 마감이 한 주에 몰린다
- 우니스가 주는 것: 강의계획서 → 캘린더로 마감 정리 · 시험 대비 팩으로 복습 속도 · (추가 예정) 졸업요건 계산기

### 민재 — 2학년 · 대외활동 3개 병행
> "오늘 뭐가 제일 급한지 모르겠어요"

- 고민: 수업·동아리·공모전 일정이 흩어짐 · 마감이 겹쳐 우선순위를 못 정한다 · 한 활동이 기록으로 남지 않는다
- 우니스가 주는 것: 오늘의 브리핑 · 급한 일 하나 추천 · 교수님 메일로 연락 고민 줄이기 · (추가 예정) 스펙 영수증

두 사람은 가상 인물입니다. 복수전공이 필수인 학생과 대외활동을 여러 개 하는 학생, 가장 바쁜 두 유형을 표현했고 10월 사전 설문으로 다듬습니다.

## 기능

### 이번 학기 핵심 4개

| 기능 | 한 줄 | 설명 |
|---|---|---|
| **강의계획서 → 캘린더** (대표 기능) | 한 장이면 한 학기 끝 | PDF나 KLAS 화면 캡쳐 속 마감을 찾아 캘린더로 |
| **오늘의 브리핑** | 눈 뜨자마자 오늘 할 일이 한 화면에 | 수업·마감·대외활동 + 지금 할 일 |
| **시험 대비 팩** | 90분 수업을 한 입 크기로 | 요약 → 퀴즈 → 틀린 문제만 다시 |
| **교수님 메일** | 보내기 전에 한 번 더 | 상황별 초안 + 보내기 전 체크리스트 |

### 추가 예정 (여건이 되면)

| 기능 | 한 줄 | 설명 |
|---|---|---|
| 우니스 리서치 | 검색은 AI가, 판단은 나의 몫으로 | 문장마다 출처, 발표 목차까지 |
| 졸업요건 계산기 | 졸업까지 남은 길을 내비처럼 | 영역별 남은 학점, 이중 인정 과목 |
| 집중 모드 | 25분만 우니스에게 맡겨 보세요 | 25+5분 타이머, 과목별 공부 시간 |
| 스펙 영수증 | 한 일은 그때그때 영수증처럼 | STAR 4칸 → 자소서 문항 추천 |


## 한 학기 시나리오

강의계획서 한 장이 한 학기 내내 이어진다.

1. **개강 첫 주 · 계획서 올리기** — 강의계획서 PDF나 KLAS 화면 캡쳐 한 장이면 한 학기 일정이 캘린더에 한 번에
2. **매일 아침 · 오늘의 브리핑** — 지금 할 일 하나를 먼저 제안
3. **시험 3주 전 · 시험 대비 팩** — 요약 → 퀴즈 → 틀린 문제만 다시
4. **필요할 때 · 교수님 메일** — 상황만 고르면 예의 바른 초안

기능이 따로 노는 게 아니라, 강의계획서에서 나온 일정이 브리핑 → 시험 대비로 흐릅니다. 발표 데모도 "계획서 → 캘린더 → 브리핑 → 시험 대비 팩" 한 흐름으로 보여 줍니다.

## 차별점

| 우니스만의 세 가지 | 설명 | 비교 |
|---|---|---|
| **먼저 움직인다** — 묻기 전에 알려 준다 | 마감·시험을 보고 할 일 하나를 먼저 제안 | vs ChatGPT · 물어봐야 답한다 |
| **하나로 이어진다** — 기능이 한 줄로 흐른다 | 계획서 → 브리핑 → 시험 대비까지 | vs 다른 앱 · 기능마다 따로 논다 |
| **우리 학교를 안다** — 우리 학교 규칙으로 | 첫 학교 광운대부터, 학사일정과 (추가 예정) 학번별 졸업요건까지 | vs 해외 앱 · 우리 학교를 모른다 |

**여섯 가지를 한곳에서 하는 건 우니스** (각 서비스의 공개 소개 기준 · 팀 조사, 2026년 9월. 우니스 칸은 추가 예정 기능까지 포함한 목표 기준)

| 할 수 있는 일 | ChatGPT | KLAS+ | 에브리타임 | 유니버 | 우니스 |
|---|---|---|---|---|---|
| 마감·일정 자동 정리 | ○ | ● | ◐ | ● | ● |
| 오늘 할 일을 먼저 제안 | ○ | ◐ | ○ | ◐ | ● |
| 시험 대비 (요약·퀴즈) | ● | ○ | ○ | ◐ | ● |
| 출처가 달린 자료조사 | ◐ | ○ | ○ | ○ | ● (추가 예정) |
| 졸업요건·복수전공 계산 | ○ | ◐ | ◐ | ○ | ● (추가 예정) |
| 대외활동·자소서 기록 | ◐ | ○ | ○ | ○ | ● (추가 예정) |

● 된다 · ◐ 일부만 · ○ 없다

**따라 하기 어려운 이유**
- **쓸수록 쌓이는 기록**: 일정과 공부 기록이 쌓일수록 다른 앱으로 옮기기 어렵습니다 (전환 비용).
- **학교 학사 데이터**: 학교별 일정·요건을 직접 정리한 표는 검색으로 얻을 수 없습니다. 광운대부터 시작합니다.
- **학생이 만든다**: 같은 학교 친구들의 피드백이 바로 기능에 반영됩니다.

## 우니스 인사이트 — 데이터 × 경영학

사용 기록을 서버에 모으지 않고, **설문·인터뷰·운영 비용**을 경영학 도구로 읽어 서비스와 학교생활을 바꿉니다.

| 재료 | 경영학 프레임 | 알아낼 것 |
|---|---|---|
| 사전 설문 (10월) | STP · 시장 세분화 | 지원형과 민재형은 무엇이 가장 귀찮은가 |
| 사후 설문 (시범 운영 후) | 사전·사후 비교, 만족도·추천 의향(NPS) | 일정·시험 준비가 실제로 편해졌나, 다시 쓸 건가 |
| 인터뷰 3명 | 고객 여정 지도, 고객이 해결하려는 일(JTBD) | 개강 → 시험까지 어디서 막히나 |
| 운영 비용 (Claude API) | 단위 경제성, 손익분기 | 학생 1명에게 드는 비용과 지속 가능한 요금 |
| 경쟁 서비스 | 포지셔닝 맵, SWOT | 우니스가 설 자리 |
| 비즈니스 모델 | 린 캔버스 | 기본 무료 + 추가 유료, 학교·취업센터 제휴 |

**확인할 가설 (사후 설문 문항으로)**
- **시간 관리 · 학생 증후군**: 과제는 마감 며칠 전에 시작할까? 대외활동이 많을수록 늦게 시작한다 → 브리핑이 D-7에 먼저 착수 제안
- **수요 계절성**: 언제 어떤 기능이 필요할까? 시험 2주 전에 시험 대비 팩이 가장 필요하다 → 시기별로 홈 화면 순서 바꾸기
- **STP · 시장 세분화**: 두 유형은 다르게 쓸까? 지원은 일정·졸업 설계, 민재는 브리핑 중심 → 첫 실행 때 유형을 고르면 맞춤 홈

| 무엇을 | 어떻게 |
|---|---|
| **성공 지표** | 시범 참가자 30명 · 사후 설문 응답 · 만족도 · 다시 쓸 의향 |
| **비교 기준** | 10월 사전 설문(말한 것) vs 시범 운영 후 설문·인터뷰(써 본 뒤) |
| **결과물** | 대학생 학기 리포트 1장, 학생·학과에 공유 |
| **원칙** | 이름 없이, 동의를 받고, 앱에는 분석용 기록을 남기지 않음 |
