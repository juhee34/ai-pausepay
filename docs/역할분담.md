## 3차 분담 (11/4~11/20) — 새 기능 + 계정 (11/4 다시 배정)

범위는 `docs/PRD.md`(⑥~⑭), 프롬프트 번호는 `docs/프롬프트.md`. 서로 같은 파일을 고치지 않도록 **"그 파일의 주인이 그 기능을 맡는다"**로 다시 나눴습니다.
- **A = 캘린더·홈·서버(AI 공용 도우미)·계정 쪽**: 캘린더 파일을 고치는 ① 평가 비율, 로그인·사용량·ICS 구독 주소

**우선순위 (11/4 결정)**: 대학 생활 전체 기준으로 1순위(바탕 + 매 학기 흐름)와 2순위(쌓일수록 가치가 큰 것)까지 이번에 합니다. 3순위(⑩ 역량 공백 지도, ⑭ 익명 통계, 학기 결산서)는 미룹니다. 작업량(일)은 대략치이고 **A 약 13.5일, B 약 14.5일**로 맞췄습니다 (B는 운영 일, A는 분석·발표 일이 따로 있음).

## 매일 지킬 습관

1. 일을 시작할 때마다 최신 `main`을 받고 새 브랜치를 만듭니다.
   ```bash
   git switch main
   git pull
   git switch -c feature/기능이름
   ```
2. PR은 작게, 기능 단계마다 하나씩. **상대방이 확인하고** 합칩니다. **PR의 base가 `main`인지** 꼭 봅니다.
3. 남의 파일을 고쳐야 하면 직접 고치지 말고 먼저 말합니다. 같은 문제를 둘이 동시에 고치지 않게 "내가 고칠게"를 먼저 남깁니다.
4. 각자 자기 `web/.env.local`에 `ANTHROPIC_API_KEY`와 `AI_LIMIT_SECRET`을 넣습니다. 키는 카톡·채팅·코드에 쓰지 않습니다.
5. 테스트에 쓴 실제 강의계획서·KLAS 캡쳐는 커밋하거나 단톡에 올리지 않습니다 (교수님 연락처 등 개인정보가 들어 있음).

## 주의할 점 (지금까지 겪은 일)

**저장소 비공개 전환 (11/20 기능 동결 직후)**
- 개발 동안은 공개로 둡니다. 동결 직후 GitHub **Settings → General → Danger Zone → Change visibility**로 비공개로 바꿉니다 (A, 저장소 주인).
- 바꾼 뒤 Vercel 무료 요금제에서 **B가 합친 커밋의 자동 배포가 막힐 수 있어요.** 막히면 A가 Vercel **Deployments → ⋯ → Redeploy**를 누릅니다.
- 비공개로 바꿔도 공개 기간에 올라간 내용은 남이 복사해 갔을 수 있어요. 그래서 키·실제 강의계획서는 지금처럼 절대 커밋하지 않습니다.

**Git·설치**
- `git add .`는 쓰지 않습니다. `.claude/` 폴더(앱 설정·작업 폴더)까지 커밋돼요. 바꾼 파일만 골라 `git add 파일이름`으로 담습니다.
- 패키지가 바뀐 PR(`package.json`)을 받은 뒤에는 `web` 폴더에서 `npm install`을 한 번 실행합니다. 안 하면 화면이 안 떠요.
- `npm run dev`는 `next dev --webpack`으로 돌아요. 기본 도구(Turbopack)는 한글 글꼴 오류가 나니 스크립트를 되돌리지 않습니다.
- 개발 화면 왼쪽 아래 검은 'N' 동그라미는 오류가 아니라 개발 모드 표시예요. 배포 사이트엔 안 나와요.

**키·Vercel**
- Vercel 환경 변수를 바꾸면 **Save 후 Deployments → ⋯ → Redeploy**까지 해야 적용됩니다. (Save만 했다가 401 오류를 겪었음)
- 키는 일부라도 캡처하거나 채팅·카톡에 보내지 않습니다.
- 하루 AI 20회 제한은 브라우저 쿠키를 지우면 풀려요. 마지막 안전장치는 **Claude 콘솔 월 사용 한도**라서 꼭 걸어 둡니다.

**검증할 때**
- 브라우저에서 '인쇄 → PDF'로 저장한 파일은 글자가 깨져 있을 수 있어요 (광운대 강의계획서가 그랬음). 캘린더는 AI가 페이지를 그림으로도 읽어서 괜찮았지만, **시험 대비 팩은 PDF에서 글자를 꺼내 쓰므로** 엉뚱한 문제가 나올 수 있어요. 시험 자료는 원본 PDF로 확인합니다.
- **구글 캘린더는 `.ics` 안의 알림을 무시**하고 계정 기본 알림을 따라요. 안드로이드에서 "전날 9시 알림이 안 온다"는 오류가 아닐 수 있어요.
- 카톡 안에서 링크를 열면 `.ics` 내려받기와 파일 고르기가 안 될 수 있어요. 검증도 **사파리·크롬**에서 합니다.
