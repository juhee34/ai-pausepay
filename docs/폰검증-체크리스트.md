# 우니스 휴대폰 검증표

CLAUDE.md의 완료 기준은 **"배포 주소를 휴대폰으로 열어서 동작"**입니다. 이 표는 `docs/PRD.md`의 '끝났다는 기준', `docs/역할분담.md`의 검증 분담, `web/README.md`의 로그인 확인 순서를 한곳에 모은 것입니다. 기준이 바뀌면 PRD를 먼저 고치고 이 표를 맞춥니다.

- **주소**: 배포 사이트 (주소는 팀 공유 메모 참고)
- **A**: 아이폰 · 사파리 / **B**: 안드로이드 · 크롬
- **상태 표기**: `미확인` → 해 보고 `통과` / `실패` / `해당 없음`으로 바꾸고, 날짜(예: 11/18)를 같이 적습니다.
- **담당**: 역할분담 문서에서 그 기준을 맡은 사람. 담당이 아니어도 자기 폰에서 되는지 보면 칸을 채웁니다.
- **보충 기준일**: 2026-11-04. PR 병합·로컬 테스트는 휴대폰 검증 통과를 뜻하지 않습니다. 미구현·미배포·자료 미준비로 실행하지 못한 항목도 `미확인`으로 두고 이유만 메모합니다. `해당 없음`은 플랫폼이 다르거나 이번 범위에서 제외한 경우에만 씁니다.

## 검증 전에 꼭 지킬 것

- 카카오톡 안의 브라우저가 아니라 **사파리(A)·크롬(B)**으로 엽니다. 카톡 안에서는 파일 고르기·`.ics` 내려받기·로그인이 막힐 수 있습니다.
- 테스트 자료는 **본인 자료나 공개 자료**만 씁니다. 실제 강의계획서·KLAS 캡쳐에는 교수님 연락처 같은 개인정보가 있으니 **이 문서·GitHub·단톡에 올리지 않습니다.** 메모에는 "계획서 3번 날짜 1개 틀림"처럼 결과만 적습니다.
- 화면을 캡처해 공유할 때는 이름·이메일·학번을 가립니다. API 키·환경 변수 값은 어떤 경우에도 적지 않습니다.
- AI 기능은 하루 20회 제한이 있습니다. 많이 시험하는 날은 나눠서 합니다.
- 실패하면 메모에 **어떤 화면 → 무엇을 눌렀는지 → 무엇이 나왔는지**를 적고, 담당에게 알립니다.
